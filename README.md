# JARVIS

Мобильный веб-ассистент для Android-браузера. Приложение хранит историю и заметки в локальном хранилище браузера.

## Подключение настоящей языковой модели

Фронтенд намеренно не содержит API-ключей. Для подключения модели используйте безопасный серверный посредник. В каталоге `server/worker.js` находится шаблон Cloudflare Worker для API, совместимого с форматом OpenAI Chat Completions.

### Развёртывание Cloudflare Worker

Перед публикацией пройдите [контрольный список готовности к развёртыванию](docs/deployment-readiness-checklist.md). Он помогает отличить проверенные настройки аккаунта от поведения, покрытого автоматическими тестами.

1. Создайте Worker в панели Cloudflare и вставьте содержимое `server/worker.js`.
2. Настройте переменные Worker:
   - `AI_MODEL` — имя модели, доступной у выбранного провайдера.
   - `ALLOWED_ORIGIN` — точный origin сайта JARVIS, например `https://ваш-пользователь.github.io` (без завершающего слеша и без пути).
   - `AI_BASE_URL` — необязательный полный адрес Chat Completions API; если не задан, используется OpenAI.
3. Добавьте `AI_API_KEY` как секрет Worker (Settings → Variables and Secrets). Никогда не вставляйте ключ провайдера в HTML, публичный репозиторий или настройки приложения.
4. **Рекомендуется:** добавьте `JARVIS_ACCESS_TOKEN` как отдельный случайный секрет Worker. Если он задан, Worker принимает только запросы с заголовком `Authorization: Bearer <токен>`. В настройках ИИ JARVIS можно сохранить этот токен локально на своём устройстве. Не используйте приложение с сохранённым токеном на общедоступных или чужих устройствах.
5. До публикации настройте ограничение расходов у провайдера и Cloudflare Rate Limiting Rule для пути `/api/chat`. Начните с небольшого лимита запросов на IP и наблюдайте за ошибочными срабатываниями. CORS ограничивает браузерные запросы, но не является аутентификацией: endpoint можно вызвать напрямую вне браузера.
6. Скопируйте адрес Worker с путём `/api/chat`.
7. Откройте JARVIS, нажмите «Настройки ИИ» и вставьте HTTPS-адрес, затем при необходимости токен доступа. Токен хранится в локальном хранилище браузера; ключ провайдера в приложение не вводится.
8. Введите обычный вопрос. Неизвестные локальные команды будут отправлены модели.

### Автоматические предложения улучшений

Workflow `.github/workflows/jarvis.yml` запускает генерацию предложений через GitHub Models и открывает PR для ручной проверки. Для него настройте секрет репозитория `MODEL_TOKEN` — отдельный токен с минимально необходимым доступом к GitHub Models (только чтение модели). Не используйте для вызова модели токен, предназначенный для записи в репозиторий. `GITHUB_TOKEN` остаётся внутри шага создания PR и использует разрешения workflow для публикации предложения. Если `MODEL_TOKEN` не задан, генерация безопасно пропускается; приложение и обычные проверки продолжают работать.

### Ограничения и безопасность

- Worker принимает сообщения до 8000 символов, ограничивает историю и отбрасывает ответы провайдера больше 256 KiB.
- Ошибки провайдера не раскрывают ответ upstream или секреты клиенту.
- Используйте только HTTPS. Перед публичным использованием настройте лимит расходов, Cloudflare Rate Limiting Rule для `/api/chat` и оповещения о расходах у провайдера. Не полагайтесь на CORS как на защиту от злоупотребления.
- История и заметки хранятся локально в браузере; сообщения, отправленные модели, покидают устройство и обрабатываются выбранным провайдером.
- Без развёрнутого Worker и действующего ключа чат остаётся в локальном режиме.
